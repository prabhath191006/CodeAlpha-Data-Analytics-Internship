# 🎬 Netflix Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project is part of the **CodeAlpha Data Analytics Internship**. The objective is to perform **Exploratory Data Analysis (EDA)** on the Netflix Movies and TV Shows dataset to understand trends, patterns, and insights through data cleaning, statistical analysis, and visualizations.

---

## 🎯 Objectives

- Load and explore the Netflix dataset.
- Understand the dataset structure.
- Identify missing and duplicate values.
- Clean the dataset.
- Perform statistical analysis.
- Generate meaningful visualizations.
- Extract useful insights from the data.

---

## 📂 Dataset

- **Dataset Name:** Netflix Movies and TV Shows
- **Source:** Kaggle
- **File:** `datasets/netflix_titles.csv`

The dataset contains information such as:

- Show ID
- Type (Movie / TV Show)
- Title
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre
- Description

## 🔍 Key Insights

- Movies are significantly more than TV Shows.
- The United States contributes the highest amount of Netflix content.
- India is the second-largest content producer.
- Netflix content increased rapidly after 2015.
- TV-MA is the most common content rating.
- Drama and International Movies are among the most popular genres.

---

## ▶️ How to Run

1. Clone the repository.

2. Install the required libraries.

```
pip install -r requirements.txt
```

3. Run the Python script.

```
python eda_netflix.py
```

4. The generated graphs will be saved inside the **outputs/graphs** folder.
